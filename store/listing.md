# Chrome Web Store listing

## Name
YouTube Parental Controls

## Short description
Set local daily YouTube watch-time, Shorts, and allowed-hours controls protected by a parent PIN.

## Detailed description
YouTube Parental Controls gives a parent straightforward, local controls for YouTube on a Chromebook or Chrome browser.

Unlike a simple website timer, it counts time only while YouTube video media is actually progressing. Daily usage and controls persist across browser restarts. Parents can set a daily watch-time allowance, optionally block Shorts or give Shorts a separate allowance, and restrict playback to chosen allowed hours or bedtime boundaries.

Parent settings are protected by a 4–8 digit PIN. The PIN itself is not stored; the extension stores a salted verifier. Settings and watch-time totals remain in the Chromebook's Chrome extension storage. No account or external server is required, and there are no ads, analytics, or telemetry.

Optional experience controls can hide selected YouTube surfaces such as Shorts links, comments, live chat, recommendations, or the home feed. YouTube changes can affect those cosmetic controls without affecting the playback timer.

This extension is a browser-level aid, not an operating-system security boundary. A person who can manage Chrome extensions may be able to disable, remove, or reset it.
